Éditeur de contenu A.P.P.L.

Éditeur local, sans connexion à GitHub : ouvrez le fichier content/site.json, modifiez-le et téléchargez la version corrigée. Remplacez ensuite le fichier dans GitHub et validez (« Commit changes »). Cette page ne publie rien automatiquement et ne gère aucun dossier confidentiel.

Pour les images : ajoutez le fichier dans assets/ via GitHub, puis renseignez son chemin dans galerie. Ne publiez aucune photo de bénéficiaire sans autorisation.
